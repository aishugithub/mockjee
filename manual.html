1. What this site is for

Many sites already run mock tests from old JEE Main papers. This one is built to diagnose a student (Akil, and since 10 Oct 2026 his friends, each with their own account):

  • which chapters he is strong or weak in, and
  • why he gets questions wrong.

Many wrong options in JEE are traps: exactly the answer you get by making one particular mistake. When the student picks one, the site names that mistake, for example "used the full-plate formula for a half-filled capacitor".

It uses real questions from NTA's public JEE Main papers (as NTA's own images) with answers from NTA's final answer key.

2. Start it on your computer

Once only: install

  1. Install Python 3 from python.org (tick "Add Python to PATH" during install).
  2. Open a terminal in the project folder (C:\Akil\MOCK JEE) and run: 
    pip install flask
  3. Make your own admin account. Replace the username and name; you then type a password (it is not shown on screen): 
    python tools/manage_users.py add-admin admin "Your Name"
  4. Akil's account already exists on this computer. To add another student (it prints a one-time password to give them): 
    python tools/manage_users.py add ravi "Ravi Kumar"

Every time

  1. Double-click run_app.bat in the project folder. (Or run python server.py.)
  2. The browser opens http://localhost:8000. Sign in.
  3. Keep the black window open while using the site. Closing it stops the site.
On this computer the tests are saved in data/akil.db. Don't delete the data folder: it holds every student's history.

3. For students: taking a test

  1. Sign in with the username and one-time password you were given. Choose your own password (8+ characters).
  2. Set up the test: duration in minutes, which years, which subjects or chapters, and the marking (default +4 / −1). Chapters marked "Not in current syllabus" are unticked by default.
  3. Take the test. The screen works like the real NTA exam:
    • Save & Next saves your answer. Moving away without saving does not save it (same as the real exam).
    • Mark for Review to come back later. "Answered & Marked for Review" still counts.
    • Numerical answers are typed with the on-screen keypad.
    • If the page closes by accident, open it again: the test resumes, but the clock keeps running.
  4. Submit. The result appears straight away:
    • score, marks gained and lost;
    • a chapter table: attempted, correct, wrong, skipped, accuracy, marks lost, average time;
    • strong and weak chapters (only chapters with 4 or more attempted questions are judged);
    • slow but correct questions (shaky areas) and wrong in under 30 seconds (likely guesses).
  5. Answer review (most important part). Each wrong or skipped question opens with the answer hidden. You can:
    • Retry it (practice only, the score does not change),
    • open Hint 1, then Hint 2,
    • see the full solution, or
    • Skip it. Skipping is allowed: nobody scores 100%, and choosing what to leave is part of JEE.
    For each wrong answer, tap why you got it wrong: didn't know the concept / silly concept mistake / silly calculation mistake / forgot a formula or fact / misread the question / rushed. Please be honest: this is what makes the diagnosis useful.
  6. If your wrong option is a known trap, the review shows "Likely trap (Claude's analysis)" and names the mistake. It appears only after you solve it, see the solution or skip, so it never acts as a hint.
  7. Progress across tests (button on the setup and result screens): all your tests together, chapter trends, your own reasons ("silly calculation mistake: 2 of 8"), traps you fell into, how far you needed hints, timing.
  8. Practise next: one click ticks only your weak chapters in the setup, ready for the next test.
  9. PDF report: download from the result screen. It has the chapter table, strong and weak chapters, and every question with your answer, the key, the likely trap and the solution.

4. For the admin: accounts

There is no public sign-up. The admin creates every account. Each student sees only their own tests; the admin sees everyone.

In the app (easiest)

Account menu (top right) → Students:

  • Add a student: name + username. A one-time password is shown once: send it privately. The student must change it at first sign-in.
  • New password: for a forgotten password. Gives a new one-time password.
  • Turn off / Turn on: stop someone using it. Their tests are kept.
  • Open any student's progress.

From the terminal (same things)

CommandWhat it does
python tools/manage_users.py add-admin <username> "<name>"Admin account; you type the password
python tools/manage_users.py add <username> "<name>"Student; prints a one-time password
python tools/manage_users.py reset <username>New one-time password
python tools/manage_users.py off <username> / onSwitch an account off or on
python tools/manage_users.py listList all accounts
python tools/manage_users.py assign-tests <username>Give tests saved before accounts existed to this user
Privacy: passwords are stored only as scrambled hashes, so nobody (not even the admin) can read them. Friends are minors: ask their parents before adding them. Deleting an account together with its tests is not built yet.

Deeper analysis by Claude

In Claude Code, in this project, say "analyse Akil's tests". The jee-analysis skill reads the saved tests, finds weak chapters and the reasons he loses marks, and writes a report. Online tests must first be downloaded with python tools/pull_db.py (see section 5).

5. Putting it online (PythonAnywhere)

Status: not online yet. It needs the owner's PythonAnywhere account. Full steps are also in DEPLOY.md.

Free account limits (checked 10 Oct 2026): 512 MB disk, 1 web app, uploads up to 100 MB each. The free web app stops after 1 month unless you extend it on the Web tab. Set a monthly reminder. Data is kept while it is stopped.

  1. On this computer, make the zip parts (about 270 MB in total, at most 80 MB each). --with-db includes the saved tests: 
    python tools/make_deploy_bundle.py --with-db
    They appear in the dist folder.
  2. Create a free Beginner account at pythonanywhere.com. Your username becomes the address: https://<username>.pythonanywhere.com.
  3. Upload and unzip one part at a time (they don't all fit at once). Files tab: upload jee_part1.zip to your home folder. Then a Bash console: 
    cd ~ && unzip -o -q jee_part1.zip && rm jee_part1.zip && du -sh ~/mockjee
    Repeat for part 2, part 3 and so on.
  4. Web tab → Add a new web app → Manual configuration (not "Flask") → newest Python 3.
  5. Open the WSGI configuration file, delete everything, paste this (put your username in), and save: 
    import os, sys
os.environ['JEE_SECURE_COOKIE'] = '1'
path = '/home/<username>/mockjee'
if path not in sys.path:
    sys.path.insert(0, path)
os.chdir(path)
from server import app as application
  6. Web tab: Static files: URL /pyq/, directory /home/<username>/mockjee/pyq/. Switch on Force HTTPS. Press the green Reload.
  7. Bash console: make your admin account, then Akil's: 
    cd ~/mockjee && python3 tools/manage_users.py add-admin admin "Your Name"
python3 tools/manage_users.py add akil "Akil"
python3 tools/manage_users.py assign-tests akil
  8. Open the site, sign in as admin, add friends on the Students page.

Later

  • Every month: Web tab → extend the web app.
  • Updating the app: make the bundle again without --with-db (otherwise the online tests are overwritten), upload and unzip only part 1, then Reload.
  • This manual online: https://<username>.pythonanywhere.com/manual. It opens without signing in, so you can read it even when you can't log in. It contains no passwords or personal data.
  • Downloading the online database for analysis: put the same JEE_EXPORT_KEY=<long random text> in .secrets on both sides (on this computer also JEE_SERVER_URL=https://<username>.pythonanywhere.com), Reload, then run python tools/pull_db.py. Keep .secrets private. Never share the PythonAnywhere password.

ExamGOAL papers (owner's decision, 25 Oct): for years NTA does not publish openly, the bank also has ExamGOAL's retyped papers with ExamGOAL's answer key: 2025 (19 shifts, 1,417 questions), 2022 (24 shifts, 2,148), 2021 (26 shifts, 2,333).   • ExamGOAL's key is not always NTA's. On the NTA papers we also have from ExamGOAL, 16 questions have a different key (list: pyq/EXAMGOAL_KEY_DIFFERENCES.md); the answer review shows a yellow "Answer keys differ" note on them. NTA's key is still used for marking. So a few ExamGOAL keys in 2021, 2022 and 2025 are probably wrong too; we cannot check those.

  • 2024, 2022 and 2021 shifts have 90 questions (10 numericals per subject); the others have 75.
  • Questions NTA dropped (or ExamGOAL marks as bonus) are left out, as are 17 ExamGOAL questions whose options did not cut out cleanly (most run onto the next page). Where two answers are accepted, either one scores.
  • Group by finer topics on the setup page uses ExamGOAL's chapter names (e.g. Waves, Circular Motion). Questions without a confident match show as "Topic not known yet".
  • There are also 84 original practice questions (questions.js). They are not NTA questions; their year is only a demo tag, and the site labels them that way.

9. Honesty rules (the owner's top priority)

  • A question is called a real PYQ only if it came from an official NTA paper. The 84 practice questions are labelled as practice.
  • Every real question carries its source (paper, shift, question ID). Answers come from NTA's final key, never the provisional key or coaching sites.
  • Only public NTA documents are used. Never a candidate's login.
  • Solutions, hints, chapter tags and traps are written by Claude and labelled that way, never as NTA's. When Claude disagrees with NTA's key, the key is not changed: the question is flagged.
  • A trap is written only when the mistake really leads to that option. Otherwise it says "No clear mistake path", and nothing is made up.
  • A subject teacher should spot-check solutions and traps, especially those marked "conceptual" (not checked by a script).
